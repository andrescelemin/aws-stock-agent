# AWS Stock Agent

AI agent solution on AWS using FastAPI, AgentCore Runtime, Cognito, LangGraph, yfinance tools, document retrieval, Langfuse observability, and Terraform infrastructure.

## Status
Project scaffold initialized.

## Planned features
- FastAPI runtime for AWS AgentCore
- Cognito authentication
- Real-time and historical stock tools
- Document retrieval over Amazon investor PDFs
- Streaming responses
- Langfuse traces
- Terraform deployment
